Benvenuto nella terza giornata del corso! L'obiettivo di oggi è esplorare le fondamenta delle architetture web moderne, imparare a creare rapidamente interfacce web accattivanti utilizzando Tailwind CSS ed integrare un database cloud NoSQL in tempo reale (Firebase Firestore) per costruire un'applicazione collaborativa interattiva.

---

## 🎯 Obiettivi della Giornata

- **Architettura Web**:
  - Comprendere la comunicazione client-server e il protocollo HTTP/HTTPS (richieste, risposte e status code).
  - Imparare a usare la console degli strumenti di sviluppo (Chrome DevTools) per ispezionare il traffico di rete.
- **Prototipazione UI**:
  - Scrivere HTML semantico e manipolare il DOM con JavaScript asincrono (ES6).
  - Utilizzare Tailwind CSS tramite CDN per la prototipazione rapida assistita da agenti intelligenti.
- **Database Real-Time**:
  - Comprendere la differenza tra database SQL e NoSQL orientati ai documenti.
  - Inizializzare un progetto Firebase Firestore e sincronizzare i dati sul frontend in tempo reale con `onSnapshot()`.
- **Progetto Pratico**:
  - Realizzare l'applicazione **"Lavagna di Post-it Collaborativa"** con salvataggio drag-and-drop persistente e sincronizzazione istantanea tra diversi client.
